# club-media

Repositorio central de recursos visuales del club, incluyendo logotipos, imágenes, iconos, material para redes sociales y otros recursos gráficos.

## Herramientas utilizadas

- La tipografía utilizada en los logotipos del club es **Cascadia Code**.
- Para crear los fragmentos de código para redes sociales utilizamos [chalk.ist](https://chalk.ist/).
- Para generar los códigos QR:
  1. Exportamos el código en formato **SVG** con [Hovercode](https://hovercode.com/).
  2. Utilizamos [Inkscape](https://inkscape.org/es/) para eliminar la imagen PNG incrustada y conservar únicamente el contenido vectorial.
- Para el QR con diseño como pixel art usamos [mosaic qr](https://mosaicqr.com)

## Créditos de imágenes

Las imágenes incluidas en este repositorio se utilizan de acuerdo con los términos de sus respectivas licencias. Cuando no existe una licencia explícita, su uso se realiza con fines no comerciales, educativos o de divulgación por parte de la asociación, procurando que pueda encuadrarse dentro de las limitaciones y excepciones aplicables, como el principio de **fair use** o figuras jurídicas equivalentes según la jurisdicción correspondiente.

Si eres titular de los derechos de alguna imagen y consideras que su uso es inapropiado, por favor abre un *issue* o contáctanos en **<cpc.gallos@gmail.com>** para revisarlo y, de ser necesario, retirarlo o reemplazarlo.
